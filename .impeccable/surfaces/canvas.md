# Surface: 创作画布

- 模式：Operate（用户来这里生图、挑图、复用提示词、把满意的存进素材库）。
- 参考：iLab CONJURE 的历史库（列表 / 网格 + 右侧详情面板），只借鉴思路，它是 AGPL，不搬代码。2026-10-19 主人确认三栏方案。
- 主要源码：`src/components/materials/MaterialCanvas.tsx`，样式在 `src/styles.css` 末尾「画布 1.8.5」一节。

## 结构

1. 生成参数栏（左）：提示词、参考图、尺寸、高级设置、生成按钮。右上角可收起成 44px 窄边，记住状态。
2. 生成记录（中）：标题和计数（共 N 个任务 · M 张图；搜索时「找到 N 个任务（共 T 个）」），「列表 / 网格」「最新优先 / 最早优先」两组分段控件和搜索框。
   - 列表：每个任务一行，左边时间、模型、尺寸和三行提示词，右边 120px 高、按原比例的缩略图。
   - 网格：正方形格子，图按原比例完整放在里面，格子下面是实际尺寸和时间；进行中的任务仍按列表行显示在上面。
3. 详情栏（右，可拖宽 300–720px）：大图（点开全屏）、同任务其他图、提醒、参数表、提示词 / 负向 / 改写后提示词（各带复制）、复用提示词（主按钮）、存入素材库、另存为、重试、取消、两步删除。
4. 窗口窄于 1080px：详情栏移到生成记录上方；窄于 960px 全部上下排。

## 规则

- 不裁图：缩略图、网格、详情栏都用 contain。
- 选中只用一处蓝：描边加浅蓝底；主按钮只有「复用提示词」。
- 操作不放在缩略图上，统一在详情栏。

## 1.8.6 补充

- 页面没有标题栏，左右边距 16px；参数栏每组之间一条细线。
- 生成中：列表里只画按目标比例的骨架占位和「生成中 0:23」，计时、尝试次数、不定进度条、关键词、失败原因只在详情栏，不重复。
- 图片加载：缩略图读完前有骨架闪光；详情栏先垫缩略图，原图读完再淡入，底边一条细线表示还在读。
- 提示词：列表三行，双击展开；详情栏六行，「展开全文」或双击展开。
- 参考图：左上角是提交顺序，拖动或方向键调整，可一键清空。
- 回填两种：「全量恢复」（主按钮）和「仅回填参考图」。
- 模板来自提示词库；生图模型在参数栏底部的下拉里直接换。
